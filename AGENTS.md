## Kanban Completion Rule

When completing Hermes Kanban tasks for this project, make the deliverable easy
for Jeff to find. Add or update `docs/KANBAN_DELIVERABLE_INDEX.md` when a task
creates a useful artifact, then leave a Kanban comment in this format:

```text
Deliverable: <absolute path or URL>
Summary: <one sentence describing what Jeff can use it for>
Next action: <what Jeff or the next worker should do>
```

Prefer direct links to concrete files, local app routes, Figma files, HighLevel
objects, screenshots, or generated reports over general statements like "done".
