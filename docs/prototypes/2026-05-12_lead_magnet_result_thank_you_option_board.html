QA checklist for any later implementation

Non-negotiables before live use

  • Default marketing consent unchecked; workflow trigger tag only after affirmative opt-in.
  • Non-subscriber path clearly says browser-only/no report email/no nurture workflow/no SMS/no DM/no social/no outbound follow-up.
  • Result copy remains educational and non-diagnostic; no promises about compliance, patentability, valuation, transaction outcome, or risk elimination.
  • Every CTA routes to the matching lead magnet/service path and remains disabled in this prototype.
  • HighLevel/Supabase/Clio/API calls stay absent during local/no-token QA.
  • Keyboard focus is visible, native controls are reachable, and mobile layout stacks into a readable single column.
